# Learn GitHub & First Contribution

## What does `git clone` do?
- [ ] Creates a new empty repository
- [x] Copies a repository, with its history, to your machine
- [ ] Uploads your code to GitHub
- [ ] Deletes your local changes

## Which command puts a change in the staging area?
- [x] git add
- [ ] git commit
- [ ] git push
- [ ] git stage --now

## What is a commit?
- [ ] A copy of the repository on GitHub
- [ ] A comment on a pull request
- [x] A saved snapshot of your changes, with a message
- [ ] A branch that has been merged

## You've committed on your laptop. What sends it to GitHub?
- [ ] git pull
- [ ] git fetch
- [ ] git save
- [x] git push

## What is a fork?
- [x] Your own copy of someone else's repository on GitHub
- [ ] A branch that can't be merged
- [ ] A bug in Git
- [ ] Two commits with the same message

## What does PR stand for?
- [ ] Push Request
- [x] Pull Request
- [ ] Public Repository
- [ ] Project Review

## Which file usually tells new contributors how to help?
- [ ] LICENSE
- [ ] .gitignore
- [x] CONTRIBUTING.md
- [ ] package.json

## Two people changed the same line. Git can't merge it by itself. That's a…
- [ ] Rebase
- [x] Merge conflict
- [ ] Detached HEAD
- [ ] Fast-forward

## What does `.gitignore` do?
- [ ] Hides the repository from search
- [x] Lists files Git should not track
- [ ] Ignores failing tests
- [ ] Blocks people from opening issues

## A good label for issues that are friendly to first-time contributors?
- [ ] wontfix
- [ ] duplicate
- [x] good first issue
- [ ] invalid
