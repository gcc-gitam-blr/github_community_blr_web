Never used Git? Good — this one is for you. On **Wednesday 7 October** we start from zero:

1. What Git and GitHub actually are, and why every developer uses them
2. Repositories, commits and issues — by doing, not slides
3. Your **first pull request** to a real repository

## Before you come

- **Make a GitHub account** at [github.com/signup](https://github.com/signup) — it takes two minutes. Use an email you'll keep after college.
- **Bring a laptop** if you have one. No laptop? Come anyway and pair with someone.
- Nothing to install in advance. We'll do that together.
