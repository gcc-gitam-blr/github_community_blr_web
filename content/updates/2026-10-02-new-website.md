This site is where everything the club does now lives.

- **[Join the club](/#join)** — leave your GitHub username and email, and hop into the WhatsApp community.
- **Every event is a page**, like a GitHub release: what it is, a calendar file, the RSVP link, and afterwards a recap and a quick feedback form.
- **[The learn hub](/learn)** — a step-by-step path from your first commit to code review, plus a searchable Git cheat sheet.
- **[Contribute](/contribute)** — beginner-friendly issues from the club's repositories, picked for first-timers.
- **[Get involved](/get-involved)** — apply to the core team, run a workshop, sponsor us, or just ask a question.
- **[Epoch](/epoch)** — booths, the coin shop, the leaderboard and your wallet.

Built by students in the club. Found something broken, or have an idea? [Tell us](/get-involved).

Follow these updates with any RSS reader: [/updates/feed.xml](/updates/feed.xml).
