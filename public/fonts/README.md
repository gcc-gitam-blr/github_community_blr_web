# Oddval (Epoch typeface)

Oddval is a commercial typeface by Type Forward: https://typeforward.com/typefaces/oddval

Drop your licensed **Oddval Medium** here as one of:

- Oddval-Medium.woff2  (best)
- Oddval-Medium.otf
- Oddval-Medium.ttf

The Epoch pages pick it up automatically. Until then they use Mona Sans.
